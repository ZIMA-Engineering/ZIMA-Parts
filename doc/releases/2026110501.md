# ZIMA-Parts 2026110501 — Debian 13 Linux release

This Linux build includes the latest Pro/E Part, Assembly and Drawing icon
restoration from Windows release 2026110302. Numbered revisions use the
original embedded role artwork.

Target: Debian 13 x86_64 with KDE/Wayland, Qt 6.8.2 and system OCCT.
Extract the archive and run `ZIMA-Parts/ZIMA-Parts.sh`. Ghostscript remains
a system dependency for PS2PDF. Other distributions are outside the supported
target. No UI text or translation keys changed.

Published archives remain immutable; this release uses a new build identity
so the existing Windows release is preserved.
