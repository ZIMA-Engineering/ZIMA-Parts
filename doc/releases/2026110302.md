# ZIMA-Parts 2026110302

This Windows maintenance release restores the original Pro/E Part, Assembly
and Drawing role icons in the Parts file list. Numbered revisions such as
`.prt.1`, `.asm.2` and `.drw.10` use the corresponding original raster icon
regardless of revision number or filename case.

This corrects build 2026110301, which restored role distinction but selected
new generic vector icons instead of the established Pro/E artwork. Pro/E Format
and Neutral files retain their application-owned vector icons. Directories,
ZIMA-CAD documents, ordinary registered files and unknown files continue to use
their existing native or application-owned icon paths.

No user-visible text or translation key changed. Czech, German, French and
Russian catalog validation remains required with English as the source-language
fallback.

## Verification boundary

Record final Windows build, test, packaging, signature and publication evidence
here after acceptance. Native Linux build and appearance remain separate host
work.
