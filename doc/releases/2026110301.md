# ZIMA-Parts 2026110301

This Windows maintenance release restores distinct application-owned icons for
numbered Pro/E Parts, Assemblies, Drawings, Formats and Neutral files. The icon
provider recognizes every numeric revision such as `.prt.1`, `.asm.2` and
`.drw.10`; the revision does not change the document-role icon. In particular,
`PRT`, `ASM` and `DRW` are visually different again.

Folders, ZIMA-CAD documents, ordinary registered files and unknown files retain
the native Windows icon-provider behavior introduced in 2026092904. Datasource
logos, thumbnails, file filtering, metadata and Pro/E version selection are
unchanged. The implementation caches the five Pro/E resource icons and does not
allocate a new type list for every displayed file.

No user-visible text or translation key changed. Czech, German, French and
Russian catalog validation passes with English as the source-language fallback.

## Verification boundary

The Windows development build passes for the GUI, CLI, updater and integration
test executable with Qt 6.10.1, MSVC x64 and OCCT 8.0.1. The complete local
matrix passes 64 integration checks, four read-only CLI checks, 14 built-in tool
checks and translation validation. The focused integration check covers
case-insensitive numeric Pro/E revisions, exact embedded icon selection,
identical icons across revisions, distinct `PRT`/`ASM`/`DRW` images, native
folder icons and native fallback for ZIMA-CAD, text and unknown files.
